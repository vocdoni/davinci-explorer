# Translation glossary

The words the explorer uses in Spanish (Spain, neutral register) and Catalan
(standard central, IEC). Every translation follows this file; change a term here
first, then in both catalogs. A recurring term the tables lack: add it when you
first translate it.

## Style

- Address the reader as `tú` / `tu`, like the English `you`. Where the English
  says "yourself", use the neutral `por tu cuenta` / `pel teu compte` rather
  than the gendered `tú mismo` / `tu mateix`.
- Spanish of Spain: the present perfect for what has just happened
  (`No se ha podido leer…`, `¿Se ha contado mi voto?`), `coste` (not `costo`),
  `tamaño`, opening `¿` and `¡`.
- Catalan: IEC spelling, `mida` (not `tamany`), `desar` for storing data.
- Sentence case in titles, labels and buttons, as in English. Months, weekdays
  and language names stay lowercase.
- Buttons, links and labels that name an action: infinitive in Spanish
  (`Copiar`, `Buscar procesos`), imperative in Catalan (`Copia`,
  `Cerca processos`), as each language's interfaces do. Navigation items that
  are verbs use the imperative in both (`Aprende`, `Verifica` / `Aprèn`,
  `Verifica`). Instructions inside running text use the imperative in both
  (`Escribe un id…`, `Escriu un id…`).
- Something in progress: the gerund in Spanish (`Cargando…`,
  `Leyendo la votación…`); `s'està` plus infinitive in Catalan
  (`S'està carregant…`, `S'està llegint la votació…`), never a bare gerund.
- Quotes: «…» in both languages, “…” inside them.
- `#3` becomes `n.º 3` (es) and `núm. 3` (ca) in titles and prose: "Batch #12"
  is `Lote n.º 12` / `Lot núm. 12`. A compact cell or badge that shows only
  `#{n}` keeps the `#`.
- Catalan: the ela geminada takes the middle dot `·` (U+00B7), never a period
  or a bullet: `cel·la`, `cancel·lat`, `col·lusió`. Straight apostrophe `'`, as
  the catalog already uses (`l'adreça`, `d'estat`).
- No apostrophe or contraction may depend on a placeholder, whose first letter
  is unknown: `de la versió {releaseLabel}`, not `de {releaseLabel}` or
  `d'{releaseLabel}`; in Spanish likewise for `al` / `del`.
- Catalan `nombre` for a count or a quantity (`nombre de vots`,
  `un nombre xifrat`), `número` for an identifier (`número de bloc`).
- Numbers, dates and relative times are formatted by the code for the active
  language: never type a separator or a date format into a translation. A
  number spelled out in words follows the long scale: "one trillion" (10¹²) is
  `un billón` / `un bilió`.
- Keep the English punctuation at the start and end of a message, and the
  single-character ellipsis `…`.
- Never translate: hex values, addresses, hashes, register names (`overall_ok`,
  `fail_mask`, `occupied_before`, `votersCount`), fail-bit names, contract,
  function, event and error names (`ProcessRegistry`, `newProcess`,
  `CensusUpdated`, `InvalidProof`), environment variables (`RPC_URL`), commands
  and code, product and project names (DAVINCI, DAVINCI explorer,
  davinci-zkvm, davinci-dkg, davinci-circom, davinci-contracts, ZisK, PLONK,
  Groth16, EIP-4844, KZG, lean-IMT, Gnosis Chain, Ethereum, Foundry, `cast`,
  `forge`), the names of primitives (Poseidon, BabyJubJub, ElGamal,
  Chaum–Pedersen, BLS12-381, BN254, secp256k1, ECDSA, SHA-256, keccak256,
  RISC-V), `c1` / `c2`, and the loanwords the tables keep: zkVM, blob, beacon,
  hash, digest, guest, gas, nonce, calldata, opcode, big-endian, little-endian,
  RPC, API, SDK, UTC.

### False friends and traps

- `prueba` / `prova` means proof only. For "try" say `intentar`
  (`se intenta con el secuenciador`, `s'intenta amb el seqüenciador`); the
  standard Retry buttons `Reintentar` / `Torna-ho a provar` are fine.
- A proof is verified: "the registry checks the proof" is
  `el registro verifica la prueba` / `el registre verifica la prova`, never
  `comprueba la prueba` / `comprova la prova`.
- "Against" in a comparison is never `contra`, in either language (see
  "checked against" below).
- "Consistent" is `coherente` / `coherent`, not `consistente`.
- "Resume" (voting) is `reanudar` / `reprendre`, not `resumir`.
- Catalan `comptar` is to count; `contar` is to tell a story.
- Catalan `signatura` is a signature; `firma` is a company.
- Catalan `fallida` alone reads as bankruptcy: a failed check is `no superada`.
- "Ready" is `Listo`, never `Lista`, which reads as "list".
- Encrypt is `cifrar` / `xifrar`, never `encriptar`. A key is `clave` / `clau`,
  never `llave`.
- The registry's record of a process (what `getProcess` returns) is `ficha` /
  `fitxa`, not `registro` / `registre`, which is the registry.

## Terms

The English follows the plain words of [docs/writing.md](../../docs/writing.md#words):
one plain word per concept in lead text and labels, the technical term in the
details layer. Both languages keep that split. **Plain** marks the word for
leads, labels, titles, tooltips and empty states; **Technical** marks a term for
the details layer only, and its note names the plain word to use instead. Use
each word the same way on every page, and never a second plain word for the
same thing.
